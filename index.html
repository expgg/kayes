Assignment Details & PC Configuration

Introduction

Building a personal computer (PC) allows for customization tailored to specific requirements and budget. This assignment details the component selection for a PC designed primarily for high-quality gaming and live streaming, capable of running demanding modern games smoothly while broadcasting gameplay online.

PC Configuration

  1. Processor (CPU): AMD Ryzen 7 5800X Reason: Excellent performance for simultaneous gaming and streaming tasks.
  2. Motherboard: ASUS ROG STRIX B550-F GAMING (or similar B550) Reason: Compatible with the CPU, provides necessary features and stable power for demanding use.
  3. Memory (RAM): 32GB (2x16GB) DDR4 3600MHz Reason: Ensures smooth multitasking between games, streaming software, and other applications.
  4. Storage: 1TB NVMe SSD (e.g., Crucial P5 Plus) Reason: Provides very fast boot and loading times for games and applications, with sufficient space.
  5. Graphics Card (GPU): NVIDIA GeForce RTX 4060 8GB Reason: Delivers strong gaming performance and features efficient hardware encoding (NVENC) ideal for high-quality streaming.
  6. Power Supply (PSU): 750W 80+ Gold Certified (e.g., Corsair RM750x) Reason: Provides stable, efficient power for all components with headroom for reliability.
  7. CPU Cooler: Noctua NH-U12S (or similar) Reason: Ensures CPU stays cool under load for stable performance during long sessions.
  8. Case: Mid-tower ATX case with good airflow (e.g., Fractal Design Meshify 2 Compact) Reason: Ensures components stay cool during long sessions and allows for easy building.
  9. Operating System: Windows 11 Home (64-bit) Reason: Modern OS supporting latest features and compatible with target software and games.
  10. Monitor: 27-inch 1440p 165Hz IPS Monitor Reason: High resolution and refresh rate provide a smooth and sharp visual experience ideal for gaming.
  11. Peripherals: Gaming Keyboard and High-Precision Mouse Reason: Input devices suitable for gaming accuracy and responsiveness.
